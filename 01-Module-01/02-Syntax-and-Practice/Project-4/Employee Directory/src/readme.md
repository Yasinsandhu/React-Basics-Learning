Final Module 1 Assessment — Independent React Challenge
Project: Employee Directory

Build a small employee directory using React.

Requirements

1. Create an array containing 5 employee objects.
2. Each employee should have:
   - Name
   - Job title
   - Department
   - Age
   - Image
   - Skills (array)
   - IsActive (true/false)
3. Create a separate EmployeeCard component.
4. Display all employees using .map().
5. Pass employee information using props.
6. Display Active or Inactive using conditional rendering.
7. Display each employee's skills using .map().
8. Show the total number of employees.
9. Give each employee card a clean, responsive design.

- Use your own logic.
